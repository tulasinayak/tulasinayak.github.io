# tulasinayak.github.io

Personal portfolio website — plain HTML/CSS/JS, no build step, no frameworks.

Live at: https://tulasinayak.github.io

## Deploy (GitHub Pages)

This repo is named `tulasinayak.github.io`, so GitHub Pages publishes it automatically:

1. Push to the `main` branch.
2. On GitHub, go to **Settings → Pages**.
3. Under **Build and deployment**, set **Source** to `Deploy from a branch`, branch `main`, folder `/ (root)`.
4. Save. The site goes live at `https://tulasinayak.github.io` within a minute or two.

Any future push to `main` redeploys the site automatically.

## Editing

Everything lives in `index.html` — content, styles and script are all in that one file. Edit it directly and push to update the live site.
